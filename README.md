# Обнаружение мошеннических транзакций

Годовой проект магистратуры «Искусственный интеллект», 2026/2027.

Проект посвящён исследованию методов обнаружения мошеннических финансовых транзакций в условиях сильного дисбаланса классов. Основная задача — сравнить методы обнаружения аномалий с моделями обучения с учителем и построить воспроизводимое решение, ориентированное на практический сценарий антифрод-мониторинга.

## Тема проекта

**Обнаружение мошеннических транзакций в условиях сильного дисбаланса классов**

## Постановка задачи

В транзакционных данных мошеннические операции обычно составляют малую долю наблюдений, поэтому задача характеризуется выраженным дисбалансом классов.

Ошибки модели имеют различную практическую стоимость:

- пропуск мошеннической транзакции приводит к потенциальным финансовым потерям;
- ложное срабатывание создаёт дополнительную нагрузку на процесс проверки и может ухудшать пользовательский опыт добросовестных клиентов.

Цель проекта — построить и исследовать модели обнаружения мошеннических транзакций, определить подходящий порог принятия решения и оценить качество моделей с учётом специфики сильно несбалансированной классификации.

## Данные

В качестве основных источников данных планируется использовать открытые наборы:

- **Credit Card Fraud Detection — ULB**;
- **IEEE-CIS Fraud Detection**.

В ходе работы будут исследованы:

- распределение целевого класса и степень дисбаланса;
- структура признаков и их связь с мошенническими операциями;
- различные типы аномальных наблюдений;
- пропуски, выбросы и особенности предобработки;
- потенциальные источники утечки данных;
- временная структура данных, если она доступна в выбранном наборе.

## Методы

Планируется сравнить два класса подходов.

### Обнаружение аномалий

- Isolation Forest;
- One-Class SVM;
- Local Outlier Factor.

### Обучение с учителем

В качестве основной модели планируется использовать **XGBoost** с учётом дисбаланса классов. При необходимости будут добавлены более простые модели для корректного базового сравнения.

Для моделей будут исследованы:

- методы учёта дисбаланса классов;
- подбор гиперпараметров;
- выбор порога классификации;
- устойчивость результатов к изменению доли мошеннических операций;
- интерпретация предсказаний.

## Оценка качества

Основной интегральной метрикой проекта является **PR-AUC**, поскольку задача характеризуется сильным дисбалансом классов.

Дополнительно будут оцениваться:

- **precision**;
- **recall**;
- **recall при фиксированном precision**;
- **ROC-AUC** как вспомогательная метрика;
- матрица ошибок при выбранном рабочем пороге.

Особое внимание будет уделено качеству модели в конкретной рабочей точке, а не только интегральным метрикам.

Проект считается успешно реализованным, если:

1. получена модель, достигающая целевого **recall при заданном уровне precision** либо превосходящая базовое решение по **PR-AUC**;
2. проведено корректное сравнение методов обнаружения аномалий и обучения с учителем;
3. исследована устойчивость модели к сильному дисбалансу классов;
4. выбран и обоснован рабочий порог классификации;
5. проведён анализ ложноположительных и ложноотрицательных предсказаний;
6. реализован или описан механизм интерпретации решений модели;
7. описан сценарий интеграции модели в процесс проверки подозрительных транзакций.
